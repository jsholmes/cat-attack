# CONCEPT_AND_FIRST_SLICE: options for Kit, not decisions
**Status:** Everything marked **PROPOSAL** is an adult/AI idea awaiting Kit's yes. Kit's own material is cited by page. No code has been written.

## 1. What Kit's pages already describe
Cat Attack, a long striped cat-snake (p1), swooshes around in loops (p2) on a board (p3). He grabs round things (p2) and meets a big-mouthed enemy (p3). A glowing egg makes him gigantic (p4). If the enemy's mouth gets him, "you lost / Levlel up" (p5). If he gets the boss, "om nom nom… you won (Rrunch!" (p6). Beating all the bosses wins the game (p5). There is a castle (p6) and dragons in the title (p6).

## 2. Probable core loop (interpretation, needs Kit)
**Swoosh → grab → (glowing egg) go gigantic → face a boss → om nom nom or get got → next boss … → all bosses beaten.**
The biggest unknown is whether "who bites who" is really the rule (Question 2).

## 4. Camera / control options (PROPOSALS)
- **A. Top-down board** (looking down at the board, like a table game). It fits "on a bord" and the loopy path. **Recommended starting point.**
- **B. Side view**: shows off the paddle feet and mega size better, but it's harder to fit loops.
- Controls for a 7–8-year-old: **steer by touch/drag or by arrow keys.** Nothing to memorise.

## 5. Playing with friends (PROPOSAL OPTIONS: Kit picks; see Question 1)
1. **Same screen, side by side:** each friend steers their own cat-snake on one board, either teamed up against the bosses or racing for the egg.
2. **Taking turns:** one player at a time and the others cheer. This is the simplest to build.
3. **Friend plays the boss:** one player is Cat Attack, the other controls the enemy (p5's "enamy vs you" layout fits this).
4. **Each on their own device:** this works later, but it needs much more setup. Not for v0.

## 6. Encounter and victory structure (PROPOSAL)
- One board holds collectibles and one boss. Beat the boss → a new board with a new boss. All bosses beaten → win (Kit p5).
- "You lost" leads to *something* Kit defines (p5's "level up" question). Until then, use a placeholder: "try again", with no penalties.
- The castle has **no assigned role** until Kit says. A placeholder could be a background shape labeled "Kit's castle: TBD".

## 7. Proposed tiny first slice, v0 (30–90 seconds, PROPOSAL)
1. Cat Attack (a placeholder based on Kit's p1 outline) appears on one board.
2. The player swooshes him around in curves.
3. Kit's round things are scattered about. Grabbing one makes a happy sound. The effect stays a placeholder until Kit decides.
4. A glowing egg appears. Grabbing it → **GIGANTIC** for a few seconds.
5. One enemy (Kit's p3 dome guy) wanders the board.
6. Gigantic Cat Attack reaches it → "om nom nom… **CRUNCH!**" → "you won" screen. If the enemy's mouth reaches small Cat Attack first → "you lost" → try again.
7. If Question 1 says "same time": add a second player's cat-snake.

## 8. Not in v0
Multiple bosses, the castle, dragons, levels/"level up", menus, saving, scores and leaderboards, online play, sound design beyond placeholders, finished art. **Never in this game:** ads, purchases, daily-login rewards, timers that nag, or required arithmetic or learning drills. If educational features ever come up, Kit decides.
